/*怎么去重，用set集合。
秤砝码问题中的集合法是一种利用集合数据结构来解决多重背包可达性问题的高效方法。该方法的核心思想是维护一个集合，记录当前所有可能达到的重量值。
集合法的实现步骤
  1.初始：创建一个空集合，用于存储所有可达的重量值。初始时，将重量0加入集合，表示不使用任何砝码的情况。
  2.处理每种砝码1：对于每一种砝码（重量为 w，数量为 c），执行以下操作：
      创建一个新的集合，用于存储当前处理完该砝码后所有可能的重量值。
      遍历当前集合中的每一个可达重量Wold。
      对于k从1到c，计算Wnew=Wold+k×w。
      将所有计算出的Wnew加入新集合中。
   3.更新集合:将新集合替换旧集合，完成该砝码的处理。
   4.统计结果：最终集合的大小即为所有可达重量的数量。
   5.优势与特点
简洁性：代码实现简单，逻辑清晰，易于理解和维护。
自动去重：集合数据结构天然具有去重功能，无需额外处理重复状态。
灵活性：适用于各种类型的背包问题，不仅限于秤砝码问题。
首先根据输入顺序，将砝码用数字序列表示，例如2个1g和1个2g，就用 1 1 2的序列表示；
set序列用来表示加入当前砝码之前能产生的重量种类；
set初始化为{0}；当第一个1g砝码放入时，则set中需要插入原先set中的所有元素+1g后的结果；即{0, 0+1};
当第二个1g加入时，则set会插入{0+1, 1+1},就变成了{0, 1, 2};
重复上述步骤加入所有砝码；则最后set的大小即为能产生的重量种类。*/
